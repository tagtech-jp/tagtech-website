# TagTech Corporate Site

noindex 状態のコーポレートサイト。商標出願完了後に公開予定。

## 技術スタック

- Next.js 16.2 Static Export
- App Router
- TypeScript (strict)
- Tailwind CSS 4.x

## 開発コマンド

```bash
npm run dev    # 開発サーバー起動
npm run build  # 静的エクスポート（out/ に出力）
npm run lint   # ESLint
```

## ビルド出力先

`out/` ディレクトリに静的ファイルが生成される。

## デプロイ先

Cloudflare Pages（tagtech.jp）
